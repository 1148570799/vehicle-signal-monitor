# Diagnostic Playbook

这是一份用于演示知识检索工具的最小诊断知识库。所有结论都必须同时附带实时
信号或监控日志证据；本文件不能单独作为故障定论。

## Over Temperature

- 阈值：冷却液温度大于 `110 °C`。
- 先保证车辆处于安全状态，再交叉验证传感器读数和原始 CAN 字节。
- 检查冷却回路、传感器供电/接地及信号缩放，保存故障前后日志。
- 告警恢复不等于根因消失，不应自动清除故障码或继续高负载测试。

## Signal Timeout

- Agent 侧数据新鲜度阈值为 `1500 ms`；C++ 监控器默认阈值为 `1000 ms`。
- 依次检查发送节点、CAN/vcan 接口、SocketCAN 接收线程和消费队列。
- 使用发送/接收时间戳区分发送端停止、总线丢帧和应用处理阻塞。

## Illegal Value

- 合法范围：车速 `0-260 km/h`，温度 `-40-150 °C`，挡位 `P/R/N/D/S`。
- 核对 CAN ID、DLC、Intel 字节序、缩放与偏移及枚举表。
- 复现时覆盖刚好位于边界和刚好越界的测试数据。

## No Data

- 没有实时信号或日志时，Agent 必须返回证据不足，不能猜测 ECU 或线路故障。
- 可先调用 `/api/v1/signals` 上报信号，或调用 `/api/v1/monitor-log` 导入 C++ 日志。
